## 🌸 Iris Dataset Visualization with Python

This project explores the famous Iris dataset using Python data analysis and visualization libraries.  
The goal is to practice basic data exploration and visualize relationships between features.

---

## 📌 Project Purpose

- Load and explore a dataset using pandas  
- Create different types of visualizations  
- Understand relationships between features  
- Practice basic data analysis workflow  

This project was created as part of a learning process in data science and machine learning.

---

## 🛠️ Technologies Used

- Python  
- Pandas
